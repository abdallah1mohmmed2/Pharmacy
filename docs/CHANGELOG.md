# سجل التغييرات — Global Enterprise Pharmacy ERP

## Iteration 1 — Full Modular Enterprise Foundation
- إضافة نظام ألوان Enterprise Dark وRTL ومكونات الأرصدة والتنبيهات والتحقق الإداري.
- إضافة نماذج الأدوية ذات 19 نقطة سريرية وتجارية ونماذج الأطراف والسندات والفواتير والتبويبات.
- إنشاء مخطط SQLite شاملاً للنواة والفروع والمستخدمين والإعدادات والتسلسل والموسوعة والدفتر والقيد المزدوج والصناديق والسندات والمبيعات.
- تفعيل مفاتيح SQLite الخارجية وWAL وNORMAL وbusy_timeout وMEMORY.
- إضافة بذر أولي للفرع والحسابات والصناديق والمحافظ والأطراف وستة أصناف دوائية تجريبية.
- إضافة محرك ترحيل معاملات البيع والسندات مع قيد مزدوج متوازن وتحديث دفتر الأطراف والصناديق.
- إضافة مزودي الجلسة وبيانات ERP والكاشير والموسوعة والتبويبات السريعة.
- إضافة لوحة مؤشرات، كاشير متعدد التبويبات، موسوعة دوائية، وشاشة الأطراف والسندات.
- إضافة اختبارات وحدات لتحويل وحدات البيع واكتمال بيانات الدواء.

## تنبيهات واعتمادات
- بيانات seed السريرية توضيحية مرجعية أولية، ويجب مراجعتها مع النشرات المحلية ومراجع صيدلانية معتمدة قبل استخدامها في قرار علاجي.
- كلمة مرور المالك ورمز المدير بيانات تأسيسية للاختبار ويجب تغييرهما قبل التشغيل الفعلي. تُخزّن كلمة المرور ورموز المدير باستخدام PBKDF2-HMAC-SHA256 مع Salt عشوائي؛ يجب تغيير بيانات التأسيس قبل الإنتاج، وإضافة سياسات تدوير الأسرار وتحديد محاولات الدخول.
- القيد المزدوج يفرض التوازن على مستوى خدمة الترحيل، ويجب إضافة اختبارات تكامل وفحوص سلامة دورية للقيود.
- عدد ملفات الدورة 15 في التسمية الأصلية، لكن البند 15 يتضمن ملف الشاشة وملف main.dart؛ لذلك يحتوي التسليم على 16 ملف Dart رئيسياً، إضافة إلى ملفات المشروع والاختبارات والتوثيق.


## استكمالات هندسية بعد البناء الأولي
- استكمال محرر الدواء ليشمل حقول النقاط السريرية والتجارية الـ19 مع حالة مراجعة صيدلانية للبيانات غير المتحققة.
- إدخال المواد الفعالة الثمانية اللازمة للأصناف الستة، بما فيها مكونات أوجمنتين وبانادول إكسترا.
- إضافة 35 إعداداً، ودليل حسابات موسع، وحركات افتتاحية للأطراف الأربعة.
- إضافة فحص الحد الائتماني، ترقيم تسلسلي للمستندات، اعتماد المدير برمز مخزن كتجزئة، ودعم الدفع المختلط.
- توسيع لوحة التحكم لتشمل آخر الفواتير والسندات وقائمة الأصناف منخفضة المخزون.
- إضافة اختبارات قاعدة البيانات ومهام CI لبناء Android APK وWindows Desktop.
- ملفات منصات Flutter تُولّد عبر `flutter create --platforms=android,windows .` عند تهيئة نسخة العمل.

- إضافة تحقق PBKDF2-HMAC-SHA256 مملح لكلمات المرور ورموز المدير، واختبارات للتحقق من التجزئة.
- تقييد استعلامات الموسوعة والأطراف والمؤشرات بالفرع النشط، وعزل حالة المريض لكل تبويب كاشير.
- إضافة حساب بنكي تجريبي، والتحقق من توافق وسيلة الدفع مع نوع حساب الصندوق، ودعم التسوية غير النقدية مع قيد متوازن.
- إضافة قيود محاسبية افتتاحية متوازنة للأطراف الجديدة وحركات الأطراف المزروعة.
- إصلاح قوس إغلاق مفقود في تخطيط قائمة موسوعة الأدوية تسبب في فشل `dart format` ضمن CI.
- معالجة القيم nullable لأعداد التعبئة قبل حساب أسعار الشريط والحبة.
- ضبط النوع الصريح لسجلات دفعات نقطة البيع لمنع استنتاج List<dynamic>.
- إعادة بناء قوائم موسوعة الأدوية بتراكيب Widget واضحة، وإصلاح استخدام BuildContext بعد الحفظ غير المتزامن.
- إضافة اختبار smoke بسيط باسم التطبيق الفعلي لمنع اختبار MyApp الافتراضي الذي ينشئه Flutter CI.
