# تبسيط إعدادات Pharmacy للمستخدم غير التقني — 14 نوفمبر 2026

## الهدف والنطاق
- المستودع: `abdallah1mohmmed2/Pharmacy`، الفرع `feature/central-medicine-catalog`.
- **35 إعدادًا موجودًا** دون إضافة إعدادات أو تغيير أرقامها أو مفاتيحها أو أنواع البيانات أو قيمها الافتراضية.
- واجهة الإعدادات والإجراءات المعروضة فقط؛ نفس `SettingsAndSystemProvider.changeSetting` و`SettingsService.setSetting`، ونفس التحقق من رمز المدير/المالك وسجل الرقابة وسلوك المزامنة والنسخ الاحتياطي.
- بدون تعديل `main` أو مخطط قاعدة البيانات أو الترحيلات.

## التغيير في تجربة المستخدم
- أسماء عربية واضحة ووصف نتيجة كل خيار بدل أسماء المفاتيح مثل `sales.price_rounding`.
- جميع الإعدادات المنطقية (**BOOL**) تستخدم `SwitchListTile.adaptive`؛ إعداد «له وعليه» الإلزامي معطل التعديل كما كان.
- جميع `allowedValues` (11 إعدادًا) تستخدم قوائم منسدلة كاملة العرض، مع أسماء عربية واستمرار حفظ القيمة الداخلية الأصلية دون تغيير. قيمة قديمة غير معروفة تبقى متاحة دون استبدال.
- الحقول العددية أصبحت بمدخل واحد مناسب للوحة مفاتيح الأرقام، والتحقق من حدود الخصم 0–100 والأيام 0–3650 قبل الحفظ.
- حقول النص العادي لا تعرض JSON أو رموز SQL. اختيار الشعار من ملف صورة على الجهاز ونسخها إلى مجلد التطبيق قبل حفظ المسار الحالي. الشعار ملف محلي ويجب إعادة اختياره عند النقل لجهاز آخر ما لم يُنقل الملف نفسه.
- **كل الإعدادات المركبة السبعة** أصبحت محررًا منظمًا بدلاً من مطالبة المستخدم بكتابة JSON:
  1. الترويسة والتذييل: حقلا نص.
  2. العملة: قائمة عملات ورمز ومنازل عشرية؛ تنبيه أن تغيير العملة لا يحوّل الأرصدة القديمة.
  3. القفل المالي: اختيار تاريخ من التقويم أو حذف التاريخ، مع تأكيد عند تقليص القفل.
  4. الضريبة: مفتاح تشغيل وحقل النسبة.
  5. ورق التقارير: الحجم والاتجاه، مع إيضاح القالب المتاح.
  6. النسخ المحلية: مفتاح التفعيل، عدد النسخ، مفتاح ضغط الملف.
  7. السحابة: مفتاح تشغيل، وإعدادات اتصال متقدمة مطوية تتضمن مزود الخدمة ومعلومات Firebase وحجم الدفعة.
- تنبيهات تأكيد قبل التغييرات الخطيرة مثل المخزون السالب، إيقاف FEFO وحظر المنتهي، تغيير توزيع أرباح الشركاء، تغيير العملة، أو تشغيل السحابة؛ متبوعًا بالتحقق من رمز المدير/المالك عند اشتراطه.
- تغيير صلاحيات الأدوار يبقى بمفاتيح Switch، مع ترجمة صلاحيات الأدوار الـ31 بالعربية وإظهار سبب عدم نجاح أي تغيير.
- ترجمنا أنواع سجل الرقابة ومستويات خطورته وحالات طابور المزامنة، مع بقاء السجلات الأصلية وبصمات SHA-256 في قسم تفاصيل فنية متقدم.
- تعرض حالة هوية المؤسسة والفرع باختصار، مع إخفاء المعرّفات التقنية خلف توسيع اختياري.

## حماية التوافق
- شاشة التحرير تنشئ خريطة `Map<String, Object?>.from(initialValue)` و**تعدل فقط مفاتيح الحقول التي غيّرها المستخدم**. تظل المفاتيح الإضافية الموروثة/المستقبلية محفوظة.
- المبالغ العشرية `double`، أعداد النسخ ومنازل العملة `int`، مفاتيح التشغيل `bool`، والقيم الثابتة تحفظ بالرمز الأصلي كما كانت.
- إعداد السحابة لا يُمس معرّف المشروع أو مفتاح الربط أو حجم دفعة المزامنة عندما يبقى القسم المتقدم مغلقًا.
- ثيم التطبيق والبطاقات والألوان وخط الحفظ والمزامنة والتدقيق لم تتغير.
