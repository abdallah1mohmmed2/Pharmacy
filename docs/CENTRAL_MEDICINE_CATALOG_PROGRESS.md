## سجل المراحل

### 2026-11-08 — المرحلة 0: الفحص والتخطيط

**الحالة: مكتملة (توثيق/تدقيق أولي فقط).**

ما تم فحصه:
- `pubspec.yaml`: Flutter، Provider، sqflite، sqflite_common_ffi، http موجودة بالفعل؛ لا حاجة لإضافة حزم في هذه المرحلة.
- `lib/data/database/database_helper.dart`: قاعدة SQLite إصدار 12، مع تفعيل foreign keys وWAL وbusy timeout.
- `lib/data/database/schema_builder.dart`: جدول `drugs` الحالي يجمع تعريف الدواء وبيانات تشغيل الفرع وأسعار البيع/الشراء والمخزون، وهو مرتبط بعدة جداول عبر `drug_id`.
- `lib/providers/pos_and_drugs_provider.dart`: نقطة تحميل وبحث الأدوية الحالية في POS، ويحمّل `drugs` الخاصة بالفرع.
- `lib/data/services/drug_import_export_service.dart`: استيراد CSV/JSON قائم ويكتب مباشرة إلى جدول `drugs`؛ يجب الحفاظ على توافقه أو تحديثه باختبارات عند تنفيذ الربط.
- `lib/screens/drugs/s08_s09_drug_encyclopedia_screen.dart`: شاشة الموسوعة الحالية يجب دمج خيار الاختيار فيها أو إضافة شاشة مخصصة بعد تدقيقها الكامل.
- قاعدة التثبيت الجديدة أصبحت بلا أصناف تجريبية في الفرع الأساس، بينما تحتفظ ببيانات التهيئة التشغيلية الأساسية.

القرارات:
1. لا نحمّل 100 ألف صنف في الواجهة.
2. الخادم المركزي هو المصدر المرجعي، وPostgreSQL هو الخيار المقترح للخادم.
3. البحث عبر API بصفحات صغيرة، مع cache محلي لنتائج البحث والمواد المختارة.
4. تنزيل نسخة كاملة للعمل دون اتصال سيكون اختيارياً وليس تلقائياً.
5. يبقى جدول `drugs` الحالي هو سجل الصيدلية التشغيلي حتى لا تنكسر المبيعات والمشتريات والمخزون والوصفات والتقارير.
6. فصل هوية الدواء المركزية عن رقم SQLite المحلي باستخدام `catalog_uuid` ثابت.
7. لا تُنسخ الأسعار أو الكميات أو الدفعات من الكتالوج المركزي.
8. يجب فحص توفر FTS5 على الجهاز، وعدم افتراضه؛ fallback آمن مطلوب.
9. لا توجد حالياً خدمة API مركزية أو بيانات اعتماد خادم في المستودع؛ لن يتم اختلاق عنوان خدمة أو مفاتيح.

## نقطة التوقف الحالية

**آخر مرحلة مكتملة:** المرحلة 0 — فحص أولي وتوثيق المعمارية.  
**المرحلة التالية:** المرحلة 1 — تدقيق كامل لمراجع `drugs` وعمليات الحفظ والاستيراد/التصدير والمخططات، ثم تصميم ترحيل يضيف مرجع الهوية العالمية بأمان.  
**لم يتم بعد:** تعديل مخطط قاعدة البيانات، إضافة واجهة، بناء API، استيراد أصناف، أو تشغيل اختبارات خاصة بهذه الميزة.
