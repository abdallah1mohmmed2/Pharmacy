# الرسائل اليدوية للعملاء والموردين وبقية الأطراف — 14 نوفمبر 2026

## النطاق
- الفرع: `feature/central-medicine-catalog` فقط. لم يتغير `main`، ولا توجد مزودات SMS أو WhatsApp API أو رسائل تلقائية.
- أزرار «واتساب» و«SMS» في تفاصيل العميل والمورد، وبطاقات الموظفين والشركاء، وقائمة مندوبي الشركات.
- يظهر محرر داخل التطبيق يعرض رقم الطرف (يمكن تغييره للرسالة الحالية فقط)، نوع الرسالة، قيمة المبلغ ورقم المستند، قالبًا قابلًا للتعديل والحفظ، ونص المعاينة القابل للتعديل.
- عند الضغط على فتح واتساب أو SMS يُنشأ رابط خارجي مع الرقم والنص. إرسال الرسالة يتم من داخل التطبيق الخارجي بواسطة المستخدم.
- لا توجد علامة «تم الإرسال»، ولا تخزين لأحداث تسليم مزعومة. نجاح فتح الرابط لا يثبت إرسال الرسالة أو وصولها.

## القوالب والمتغيرات
- قوالب: تذكير رصيد عميل، تأكيد استلام دفعة، إشعار مستحقات مورد، إشعار سداد مورد، إشعار مالي موظف أو شريك، مندوب، وإشعار عام.
- متغيرات: `{name}`، `{amount}`، `{document}`.
- يعبأ الرصيد الختامي الموجب بحسب طبيعة العميل أو المورد في قوالب التذكير؛ لا يستخدم رصيد الحساب على أنه قيمة دفعة مسددة.
- عند اختيار «رسالة عن هذه الحركة» من حركة حساب: يُؤخذ مبلغ الحركة، ويُقرأ رقم السند المعلن من `vouchers.voucher_no` أو رقم فاتورة البيع `sales_invoices.invoice_no` بعد تحقق الطرف والفرع، عند توفرهما. لا يستخدم معرف `doc_id` الداخلي على أنه رقم المستند.
- قوالب استلام الدفعة والسداد لا تختار تلقائياً إلا عند تطابق نوع السند الفعلي: قبض للعميل أو صرف للمورد. ويمكن للمستخدم اختيار أي قالب مسموح وتعديل البيانات يدوياً.
- لا يسمح بفتح التطبيق الخارجي مع متغير `{amount}` أو `{document}` لم يعبأ بعد، إلا إذا غيّر المستخدم صياغة الرسالة وحذف المتغير بنفسه.

## الحفظ والنسخ الاحتياطية
- تُحفظ القوالب عند الضغط على «حفظ القالب» في جدول `app_settings` الحالي ضمن مفاتيح `messaging.manual.template.*`.
- هذه إعدادات محلية ضمن قاعدة SQLite الموجودة، وتدخل في النسخ الاحتياطية الكاملة للقاعدة دون تعديل المخطط أو النسخ الاحتياطي أو الجداول المالية.
- النص الذي يعدله المستخدم للرسالة الواحدة لا يحفظ كقالب إلا بالضغط صراحة على زر الحفظ.

## التشغيل والتحفظات
- WhatsApp: يُفتح رابط `https://wa.me/<international-number>?text=...` بعد فحص الرقم؛ يلزم رقم دولي صالح. قد يفتح الجهاز المتصفح أو واتساب بحسب البيئة.
- SMS: يُفتح `sms:<number>?body=...`، ويتطلب وجود تطبيق رسائل يدعم الرابط. قد لا تتوفر هذه الوظيفة على بعض أجهزة Windows.
- فتح التطبيق الخارجي قد يفشل عند عدم وجود تطبيق مناسب؛ تظهر رسالة خطأ واضحة ولا تنشأ عملية إرسال.
- لا تغييرات على ملف ألوان الثيم أو `SmartExpandableCard` أو قيود العمليات الحسابية.

- يعتمد البناء والتحليل النهائيان على نتائج GitHub Actions المرتبطة بالتزام الفرع بعد هذه التغييرات؛ لا تُعلن النتائج ناجحة قبل التحقق منها.
