# F08 — بوابة تهيئة المزامنة المالية الآمنة

**الحالة:** IN_PROGRESS — انتظار CI.

أضيفت `FinancialSyncConfiguration` كبوابة اختيارية منفصلة عن مسار المزامنة العام. القيمة الافتراضية `enabled=false`، ولا يوجد تشغيل مجدول أو تفعيل إنتاجي.

تتحقق البوابة قبل الاتصال من تفعيل صريح، ومطابقة الفرع المصرح به، ووجود endpoint HTTPS خالٍ من userinfo/query/fragment وبمسار `/v1/operations`، وموفر رمز مصادقة غير فارغ. ثم تفوض إلى `FinancialVoucherRelayWorker` الموجود بدلاً من إعادة كتابة النقل.

الاختبار الجديد يثبت رفض أربع حالات قبل أي طلب HTTP: معطل، فرع مخالف، مصادقة مفقودة، ورابط HTTP؛ ويثبت بقاء Outbox معلّقاً.

**حدود مهمة:** هذا حدّ حماية على العميل فقط؛ `authorizedBranchId` ليس إثباتاً لصلاحية الخادم. لا يجوز اعتماد الإنتاج قبل تحقق الخادم من Firebase ID token وclaims الفرع والأدوار والعمليات والتوازن. لم يتم ربط هذه البوابة بواجهة تشغيل تلقائي أو تخزين أسرار.
