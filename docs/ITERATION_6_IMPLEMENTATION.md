# تنفيذ الدورة السادسة — إعدادات النظام والاستيراد والرقابة والنسخ والمزامنة

## نطاق التنفيذ
هذا الفرع مبني على `feature/iteration-5-reports-pdf-55` ويضيف ترقية قاعدة البيانات إلى الإصدار 9 دون تعديل `main`.

## الملفات الأساسية
- `lib/core/constants/setting_keys.dart`: تعريف مفاتيح ومواصفات الإعدادات الـ35، مجموعاتها، أنواعها، القيم الافتراضية، القيم المسموحة، ومتطلبات رمز المدير.
- `lib/core/utils/label_guard.dart`: كشف المصطلحات المحاسبية التقليدية وتنظيفها ورفض النص غير المطابق.
- `lib/data/models/settings_audit_sync_models.dart`: نماذج الإعدادات ومهام الاستيراد ونتائج OpenFDA وسجل الرقابة وسلسلة التجزئة والنسخ والمزامنة والفترات والصلاحيات.
- `lib/data/database/schema_iteration6.dart`: ترقية جداول الإعدادات ومهام الاستيراد وسجل الرقابة والنسخ والمزامنة والفترات والأدوار والصلاحيات.
- `lib/data/services/settings_and_audit_service.dart`: كاش الإعدادات والتحقق من الأنواع والقيم ورمز المدير، مزامنة إعداد توزيع الشركاء مع `app_settings`، تفريغ العمود غير النشط، حارس الفترات، وسلسلة SHA-256.
- `lib/data/services/drug_import_export_service.dart`: قراءة CSV/JSON، الفحص المسبق، تنفيذ دفعات المعاملات وسياسات التعارض، إعادة بناء فهرس البحث، التصدير مع BOM وإخفاء التكلفة، وOpenFDA.
- `lib/data/services/backup_and_sync_service.dart`: نسخ SQLite عبر VACUUM INTO، ضغط GZip، SHA-256، تدوير النسخ، استعادة موثقة، تجميع السجلات المحلية، واختبار /ping وإرسال دفعات المزامنة.
- `lib/providers/settings_and_system_provider.dart`: حالة الإعدادات والاستيراد والتصدير والنسخ والمزامنة وسجل الرقابة والفترات والمستخدمين والصلاحيات.
- `lib/screens/drugs/s10_drug_import_export_screen.dart`: تبويبات CSV/JSON وOpenFDA والتصدير وسجل المهام.
- `lib/screens/settings/s28_system_settings_backup_screen.dart`: 11 تبويباً للإعدادات والأدوار والمستخدمين والنسخ والمزامنة والرقابة والفترات.
- تحديث `lib/data/database/database_helper.dart` و`lib/main.dart` و`lib/screens/app_shell.dart` وربط النسخ بعد إغلاق الوردية وعند إغلاق التطبيق.
- تحديث تقرير R54 ليقرأ مخطط سجل الرقابة الجديد ويعرض نتيجة سلامة السلسلة.
- اختبارات `no_forbidden_terms_test.dart` و`algorithms_and_invariants_test.dart` و`iteration6_schema_test.dart`.

## ضمانات البيانات
1. يحفظ ترحيل الإعدادات القديمة في `system_settings_legacy_i5` ثم ينقل القيم المطابقة إلى المخطط الجديد.
2. يحفظ سجل الرقابة القديم في جدول تاريخي ثم ينقله إلى سلسلة التجزئة الجديدة مع إعادة حساب البصمات.
3. يمنع SQLite تحديث سجلات `audit_logs` أو حذفها بمشغّلين مستقلين.
4. يُحافظ على مخطط المستخدمين القديم ويضيف `system_role_code` لتوسيع الأدوار السبعة دون إعادة بناء جدول مرجعي له مفاتيح خارجية.
5. يزامن الإعداد 27 مع `app_settings` التي يقرأها محرك توزيع الشركاء، ويفرغ `percentage` عند وضع الحصص أو `shares_count` عند وضع النسب قبل تبديل السياسة.
6. تُنشأ مشغّلات SQL تمنع الكتابة داخل الفترات المقفلة على جداول المعاملات المالية والمخزنية التي تحتوي أعمدة التاريخ المحددة.

## نقاط التحقق قبل اعتبار الدورة مكتملة
- يلزم انتظار نجاح Flutter Format وFlutter Analyze وFlutter Test وبناء APK وبناء Windows على هذا الفرع.
- يجب التأكد من نجاح اختبار ترحيل قاعدة بيانات موجودة من الإصدار 8، لا قاعدة جديدة فقط.
- يجب التحقق من تشغيل OpenFDA على اتصال إنترنت فعلي، واستعادة نسخة مضغوطة على جهاز اختبار، واختبار خادم مزامنة يطبق عقد `/ping` و`/sync/batch`.
- يجب اختبار State-Lock من واجهة الشركاء ومن خلال SQL المباشر على قاعدة فعلية، والتأكد من أن تقرير R54 يعرض حالة التحقق.
- لا يُدمج هذا الفرع في `main` قبل اجتياز كل هذه الفحوص ومراجعة طلب السحب.

## حدود معروفة أثناء المراجعة
- خدمة المزامنة تنفذ عقد HTTP متوقعاً: `GET /ping` و`POST /sync/batch` مع قائمة نتائج تحتوي `id` و`status`. يجب اعتماد العقد مع الخادم الفعلي قبل الإنتاج.
- ضغط النسخ GZip وليس تشفيراً؛ حقل `encrypted` يبقى false ولا يجوز تقديم النسخة على أنها مشفرة.
- بيانات OpenFDA مستوردة كمسودة للمراجعة الصيدلانية، ولا تُعامل كاعتماد سريري نهائي.
- صلاحيات الواجهات تُفلتر حسب الدور، لكن يلزم استمرار إضافة فحوص الصلاحيات داخل كل خدمة حساسة لمنع الاعتماد على إخفاء عناصر الواجهة وحده.
